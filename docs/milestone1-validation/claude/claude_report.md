## 5. 結論（Claude 單方）

目前的設計**還不能說「至少滿足」Milestone 1**：Workflow 3、7、8 的主幹可以走通，但 1、2、4、5 都有卡關或資料錯誤。最需要先處理：

1. **開新期**（C-01、C-02、C-06、C-07）：補「開始新的一期」入口，並且在同一個動作裡把上一期角色帶進新期、把舊期設成唯讀，避免組長被鎖在外面。
2. **成員家別編輯的資料錯誤**（C-03）：改家別時角色要一起搬，列表要取現行的 membership。
3. **家內教案對撰寫者、驗收者開放，並把上傳入口移進來**（C-04、C-15、C-16）。
4. **附件上傳失敗要看得見，送出前要擋或警告**（C-05、C-20）。
5. **缺交紀錄改成以教案為單位，可以先存，組長看得到逐筆明細**（C-10、C-11、C-12）。
