## 2. Codex 指出 Claude 需更正的地方

1. **Workflow 3 改 🟡、US-06／07 要出方案**：接受。新增 `s11_schedule.html`、`s12_rubric.html`，各有 A／B／C。
2. **空白頁 → 轉址**：接受（見 #4）。
3. **#3 不外推到教案歸屬**：接受。
4. **快照凍結 ≠ 整個送件結果不可變**：接受。原型 S6 送出後的畫面註明「送出時的版本」。
5. **「明細都在 DB」要限縮**：接受。現有資料只有 `reason` 與 `missing_count`，加一支 GET API 仍不滿足 US-10。
6. **500 錯誤**：接受（#27）。
7. **教案詳情回傳 null**：接受（#28）。
8. **退團依動作矩陣定義**：接受。S3 原型改成「清空本期角色」與「移除家別身份」兩個獨立動作，並列出清空後還能看什麼。
9. **改了電光家長 demo 帳號的密碼**：接受。總結改用中性寫法：「偏離本次驗證任務明列的『不改密碼』限制；測後已還原」，不再討論這條限制由誰提出（第三輪依 Codex 建議更正）。
10. **「Codex 推薦」的標示**：接受。總覽改成「Codex 審查後：修正後推薦 A」，並把 S4-B、S7-B、S5 認領機制等標成「變體」或「假設」。
