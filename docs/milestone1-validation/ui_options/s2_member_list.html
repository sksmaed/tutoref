S2｜成員搜尋與篩選

對應 US-03，以及 US-05 的「未選擇時不用出現提醒的區塊」。

情境

開完 27 冬、帶入上一期成員後，組長要找出「電光、新武兩家所有撰寫者」確認名單；也可能切回 26 夏查某人當時的家別。表格要能看出每個人的帳號狀態（例如還沒設定密碼的新成員）。

目前遇到的問題

  • C-08 沒有期別、角色篩選，家別只能單選，沒有「狀態」欄。
  • C-09 沒選人時仍顯示「已選 0 位成員」的提醒列。
  • C-03 改過家別的成員，家別欄會顯示「—」（後端要先修）。

需要先確認的規則

「同期不同家別，要分成多筆資料」是需求明文，原型照需求畫（陳怡君同時是電光、新武的撰寫者，分成兩列）。目前的資料模型一人一期只能有一個家別，要做到得先改後端 membership 模型；如果要改成一人一列，請當成需求變更另外決定，不要因為模型限制就默默降規。
表格的「帳號狀態」：已啟用 已設定密碼可登入、待認領 組長建立但本人還沒設定密碼；「本期有沒有角色」則看角色欄。

版面與互動

表格上方一列放齊四個條件：期別（必填，預設現行期）、姓名搜尋、家別多選、角色多選。套用中的條件以標籤顯示，可單獨移除；右側顯示「共 N 筆身份／M 人」。勾選成員後，批量操作列才出現。沒有結果時保留條件並提示「清除家別與角色」；切到舊期時表格唯讀、不提供批量編輯。

優點

  • 四個條件都直接看得到，最好上手
  • 和現有成員管理頁的工具列位置一致，改動小
  • 條件標籤讓「現在篩了什麼」一目了然

缺點

  • 窄螢幕時工具列會換成兩行
  • 之後再加條件，工具列會越來越擠
Claude 與 Codex（審查後）都推薦 A。需求只有四個條件，全部攤開最直覺。家別、角色採「同一類任一符合、不同類都要符合」。清除條件時保留期別，只清家別與角色。

版面與互動

常駐的只有期別與姓名搜尋；家別、角色收進「篩選」按鈕打開的右側抽屜，以膠囊按鈕複選，按「套用」後回到表格，條件以標籤顯示，並顯示套用後的筆數與人數。抽屜裡的「帳號狀態」「本期無角色」是額外的選配條件；「清除」只清抽屜裡的條件，不清期別與搜尋。

優點

  • 主畫面最清爽，窄螢幕比較好排（原型未畫手機版）
  • 之後要加條件（例如「本期無角色」）不會擠爆工具列

缺點

  • 常切換家別時每次都要多開一次抽屜
  • 條件藏起來，新手可能不知道能篩角色
如果之後篩選條件會越來越多，或常在小螢幕上操作，選 B。

版面與互動

表格上方是一排可複選的家別膠囊（附身份數），表格依家別分組，每組有小標題列；角色用多選下拉。同一個人如果同期在兩家，兩個分組都會出現，並標示「同一帳號」。「全選」只選目前看得到的列，批量列會顯示去重後的人數。清除條件只清家別與角色，不清期別；切到舊期時表格唯讀。

優點

  • 開期後「一家一家盤點名單」最直覺
  • 各家人數一眼看到，容易發現哪家還沒有家長

缺點

  • 六家全開時表格很長
  • 跨家排序、全選的行為比較複雜
如果開期時最常做的事是「逐家確認家長、撰寫者有沒有到齊」，C 最貼近這個工作方式。
