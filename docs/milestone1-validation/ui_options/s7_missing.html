S7｜以教案為單位登記缺交

對應 US-10、Workflow 6：一份缺交的教案登記一筆（預計教案名稱、姓名、缺交內容），可以編輯與刪除。

情境

電光家長在送出初驗前發現：王小明的「小小氣象員」還沒交教案紙；李小華的「彩虹從哪裡來」也還沒交教案紙。家長先登記兩筆，隔天再回來確認、修改其中一筆後送出。

目前遇到的問題

  • C-11 只有「姓名或原因」一個文字框＋份數，沒有教案名稱與缺交內容欄位。
  • C-10 送出前不存檔，重新整理就全部消失；同家其他家長看不到。
  • C-12 送出後家長、組長都只看得到份數，看不到明細。

三個方案共同的規則

  • 每筆缺交都即時存到後端（草稿），同家家長都看得到、改得到；送出時一起凍結。
  • 「姓名」可從本家成員選，也可以手動輸入（還沒加入系統的人）。
  • 缺交內容依輪次：初驗只會缺教案紙；總驗才多「投影片」可勾。下面原型畫的是總驗也適用的版本。
需要你決定：「缺交內容」在初驗是否也要能勾「投影片」？依 Workflow 4「投影片到總驗才提供」，原型在初驗把投影片選項設為停用。

版面與互動

家內教案下方獨立一塊「缺交教案」，每列一份：預計教案名稱、姓名、缺交內容、登記人、操作（編輯／刪除）。按「＋ 登記缺交」開彈窗填一筆，名稱與姓名必填、缺交內容可複選。按儲存後顯示「已儲存」，同家家長都看得到；同一人缺兩份就是兩列。刪除時會再確認教案名稱；送出後整塊變唯讀，家長與組長都看得到逐筆明細（S10）。

優點

  • 一列＝一份教案，欄位與需求完全對應
  • 彈窗內可以做必填檢查，資料最乾淨
  • 和實際上傳的教案分開，不會混淆

缺點

  • 一次登記很多筆時要反覆開彈窗
Claude 與 Codex（審查後）都推薦 A。每家每輪缺交通常只有幾份，彈窗多一步不是問題；換來的是名稱、姓名、內容都不會漏填。

缺交區塊本身就是可編輯表格：按「＋ 新增一份」多一列空白列，直接在格子裡填名稱、選姓名、勾缺交內容；每列離開時自動儲存，並在該列顯示「已儲存／儲存中／待修正」。有錯誤的列會保留輸入、標紅，不會被悄悄丟掉；所有列都儲存成功才能送出驗收。

優點

  • 一次登記多份最快
  • 畫面和現有的「註記缺交」最接近，改動直覺

缺點

  • 「還在編輯」和「已儲存」的狀態要做得很清楚
  • 表格內的下拉、勾選在手機上比較難按
如果某幾家每輪常常缺很多份，B 的連續輸入會比較順手。

版面與互動

缺交不另開區塊，而是在家內教案清單裡建立「預計教案」列，狀態標「缺交」，附件欄顯示缺的是哪一份。之後撰寫者真的上傳時，可以把新教案對應到這一列，缺交改成已上傳。自動對應只限還沒送出的草稿，送出後的缺交紀錄不會被改寫；同名不同人時要由撰寫者確認，不靠名稱猜。

優點

  • 從「預計要交」到「已交」可以完整追蹤
  • 不會發生同一份教案既缺交又已上傳的矛盾

缺點

  • 要新增「預計教案」與正式教案的配對機制，超出 Milestone 1
  • 清單裡混著真教案與預計教案，閱讀負擔較重
長期最完整，但工程量大；建議作為之後的方向，Milestone 1 先做 A 或 B。
