S12｜制定與採用本期評分標準

沿用方案 A 的固定格式編輯，分開提供「人工編輯」與「匯入企劃書」入口。兩種方式都先建立草稿、確認變更後再採用；本期使用的版本另有完整檢視頁。

兩個制定入口

人工編輯：以目前版本為基礎，調整類別、檢核項目、扣分、底分及門檻。

匯入企劃書：上傳文件，由後台解析並對應系統欄位，顯示出處與待確認項目，經人工檢查後帶入草稿。

採用與版本規則

初驗採底分扣分制；總驗維持教案紙／投影片分開判定。已分配任務維持原版本，之後新分配任務使用新版本。

A-2 改以「項目／變更前／變更後」比較，分開呈現計分變更、條文變更與影響範圍，避免把資訊塞在同一格。

互動 UI 原型：可切換初驗／總驗、編輯草稿、預覽解析及確認採用。匯入採內建示意資料，不讀取文件內容、不呼叫後台、不寫入正式資料；重新整理會還原。
