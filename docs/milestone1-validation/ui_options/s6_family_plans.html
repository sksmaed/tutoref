S6｜家內教案（採用 A＋C）

撰寫者與非家長成員採方案 A 的完整表格；家長採方案 C 的階段分組，可依驗收階段查看。兩種視角共用相同的欄位、輪次切換、附件連結與狀態樣式。

角色與呈現方式

  • 撰寫者、驗收者及其他非家長成員：完整表格檢視本家教案；只有撰寫者能在送出前上傳及管理自己的附件。
  • 家長：依「本輪待驗收／準備中／已驗收」分組，可篩選階段、展開或收合；負責納入本輪、缺交登記與送出驗收。
  • 同時具有家長與撰寫者身份時，採家長分組視角，另依撰寫權限顯示自己的上傳入口。查看範圍限本人所屬家別。

共用規則與視覺

  • 共用八個欄位；家長分組仍保留完整表頭，避免切換視角後找不到資訊。
  • 「初驗／總驗」是驗收輪次；「準備中／本輪待驗收／已驗收」是該輪教案階段，兩者分開切換。
  • 初驗僅檢查教案紙，投影片於總驗開放且選填；附件失敗或處理中不標示已繳，也不能納入本輪。
  • 送出後唯讀，附件保留送出時版本；缺交不進本輪驗收，結果公布後才呈現驗收結果。
