S6｜家內教案（撰寫者、驗收者、家長共用）

對應 US-09、Workflow 5，以及 US-11 的「同家所有人都能檢視已送出的教案」、US-12 的「家內教案頁有上傳按鈕」。

情境

27 冬初驗期間，電光家的撰寫者小美、驗收者一、電光家長都打開「家內教案」：撰寫者要上傳、看自己的教案狀態；家長要確認後送出；驗收者想先看看家裡有哪些教案。送出後大家都還要能點開教案紙。

目前遇到的問題

  • C-04 撰寫者、驗收者側欄沒有「家內教案」，直接開是空白頁；也沒有上傳按鈕。
  • C-18 表格沒有家別欄、沒有教案紙／投影片連結。
  • C-05 附件上傳失敗時畫面沒有提示，還顯示「已繳」。

三個方案共同的規則

  • 「能看本家」和「能代表本家送件」分開：側欄的家內教案對本期有家別的撰寫者、驗收者、家長都顯示；只有家長有「送出驗收」與缺交登記。
  • 初驗只檢查教案紙；投影片欄在初驗顯示「總驗開放（選填）」，不會因為沒有投影片就標「缺附件」。
  • 附件以具名連結呈現（「查看教案紙」），上傳失敗明確標示並讓撰寫者重新上傳。
需要你決定：「撰寫者」欄顯示上傳的帳號（撰寫者小美），還是教案紙上寫的設計者（○○○）？原型以帳號為主、在下方小字附上教案紙上的名字。

版面與互動

一張表放齊 US-09 的欄位：教案名稱、撰寫者、家別、類別、教案紙、投影片（總驗才顯示連結）、待驗收（本輪是否納入）、驗收狀態。頁首依角色顯示不同按鈕：撰寫者看到「上傳教案」，家長看到「送出驗收」。送出後表格與連結都還在，只是變成唯讀。

優點

  • 欄位和需求一一對應，大家看到的是同一張表
  • 附件直接點開，不用多一步
  • 現有頁面加欄位即可，改動最小

缺點

  • 欄位多，窄螢幕要橫向捲動
  • 同一頁給三種角色用，按鈕要依權限細分
Claude 與 Codex（審查後）都推薦 A。需求明確列出表格欄位；把它們全部放進同一張表，最不需要額外說明。

版面與互動

主表只留最常看的欄位（教案名稱、撰寫者、類別、附件摘要、驗收狀態），家別寫在頁首。點教案名稱從右側打開教案詳情抽屜：教案紙、投影片連結、簡介、送出快照與驗收歷程都在裡面。

優點

  • 主表欄位少、好掃讀，窄螢幕比較好排（原型未畫手機版）
  • 抽屜可以放更多資訊（簡介、歷程），日後好擴充

缺點

  • 不符合「欄位都在表格上」的嚴格解讀
  • 看附件要多點一次
如果家長常在小螢幕上確認，或之後想在同一處看驗收回饋，B 比較有延伸空間。

版面與互動

同一頁依階段分成三個可收合的區塊：「準備中（還沒納入本輪）」「本輪待驗收」「已驗收」。每個區塊用同樣的完整欄位表格；家長在「本輪待驗收」上方看到送出摘要與按鈕。

優點

  • 「全家所有教案」和「這輪實際送出的」分得最清楚
  • 已驗收完的不會干擾目前要處理的

缺點

  • 一頁多張表，教案在區塊間移動時容易找不到
  • 改動量比 A 大
如果一家每輪有十幾份教案、又常有「這輪先不送」的情況，C 的分組會比較好管理。規則：只有家長能改「納入本輪」；附件失敗的教案不能納入，送出時要登記成缺交（見 S8）。
