S5｜新增成員、通訊錄匯入與授權認領

採用方案 C，整合原 S2.5：單人新增或批量匯入 → 預覽 → 確認儲存 → 選取成員、指派角色與寄送授權信 → 本人選擇帳號連結認領。

User story

身為組長，我希望能單人新增或批量匯入通訊錄，預覽確認儲存後，能在與 S2 相同的成員管理介面中選取一位或多位成員，透過一頁式彈窗統一指派系統角色並寄送授權信，讓成員點擊信中連結、自行選擇帳號登入並確認連結認領後完成啟用，並讓我從狀態欄確認誰已啟用。

單人新增／批量匯入 → 預覽名單 → 確認儲存 → 選取成員 → 寄送授權彈窗確認成員與權限 → 寄出授權信 → 成員點擊信中連結 → 自行選擇帳號登入並確認連結認領 → 狀態顯示「已啟用」

桌機 UI 原型：可切換新增方式、預覽、儲存至示意名單、選取成員、指派角色及模擬寄信。通訊錄使用內建 xlsx 示意資料，不會讀取真實檔案、寫入正式資料、寄信或登入；重新整理會還原。

下方先展示已儲存的 6 位示範成員；上方新增資料須在 02 確認儲存後才會加入。保留 S2 的家別分頁、固定篩選列與表格欄位。新增與匯入後的角色欄先保持空白。點選單人成員列或勾選多人，再點「寄送授權」；彈窗列出所選成員與通知信箱，選擇要指派的權限後按「寄出授權」。

狀態欄說明

沿用 S2 的「帳號狀態」欄呈現本次流程：未寄送 → 待認領 → 已啟用。成員由授權信連結以自己的帳號登入並確認連結認領後，才顯示已啟用；組長只管理名單與角色，不會建立成員帳號；匯入通訊錄與儲存角色都不會自動啟用。
