S4｜批量編輯成員

對應 US-05 批量編輯：直接以橢圓選項呈現目前家別與角色，點擊即可複選或取消，儲存後套用至所選成員。

情境

匯入通訊錄並完成角色指派後，組長勾選 3 位電光家的撰寫者，批量調整家別或增加驗收者角色。開啟彈窗時，電光與撰寫者已呈亮色，直接點選其他橢圓選項即可調整。

目前遇到的問題

  • C-09 家別只能單選；角色只能「新增一個」，不能覆蓋或移除；沒選人時也顯示提醒列。
  • C-03 批量換家別時角色不會跟著搬，資料會分家（實測已重現）。

選取方式

家別與系統角色直接複選：亮色代表已選，灰底代表未選，再點一次即可取消。所有系統角色放在同一列。此例所選 3 人目前都是電光家的撰寫者；批量成員屬性不同時，共同屬性顯示亮色，部分成員擁有的屬性以虛線標示「部分」，點擊可統一選取或取消。

版面與互動

勾選成員後點「批量編輯」開啟一頁式彈窗，直接顯示本期家別與角色的橢圓選項。依目前屬性預先亮起，點擊切換選取；確認後直接儲存，不另設模式或摘要區。

優點

  • 目前家別與角色一眼可見
  • 直接點擊即可複選，操作與 S3 一致
  • 單頁完成編輯，畫面簡潔

注意事項

  • 多人屬性不同時，以「部分」標示混合狀態
  • 儲存會將點選的屬性調整套用至所選成員
採用方案 A：彈窗直接複選。家別與角色依目前狀態顯示亮色；所有系統角色在同一列點選。
