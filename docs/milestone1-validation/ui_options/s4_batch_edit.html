S4｜批量編輯成員

對應 US-05 批量編輯：本期家別、角色都可複選並直接覆蓋原本的值，沒動的欄位維持「不變更」。

情境

帶入上一期名單後，組長勾選 3 位今年轉到電光的成員，一次把他們的本期家別改成電光、角色改成撰寫者；另外選 2 位退團的人，把本期角色清空。

目前遇到的問題

  • C-09 家別只能單選；角色只能「新增一個」，不能覆蓋或移除；沒選人時也顯示提醒列。
  • C-03 批量換家別時角色不會跟著搬，資料會分家（實測已重現）。

三個方案共同的規則

每個欄位都有三種狀態：不變更（預設）／取代為（選好的值會完整蓋掉原本的）／清空（只有角色有）。家別與家別角色（家長、撰寫者）同時取代時，代表「這些人在每個選定的家都擔任這些角色」；驗收者、教案組長是全期角色，另外設定，不會套到每一家。按下套用前一定先看到變更摘要，避免以為是「追加」。

版面與互動

勾選後出現批量列，按「批量編輯」開彈窗。家別、角色各有「不變更／取代為」兩種模式，選「取代為」才展開複選膠囊；角色多一個「清空本期角色」。下方即時顯示變更摘要（幾人會改成什麼），確認後套用。

優點

  • 「不變更」和「清空」語意分得最清楚
  • 沿用現有 Dialog＋BulkActionBar，改動小
  • 摘要讓人在按下前就知道是覆蓋不是追加

缺點

  • 多一層模式切換
  • 看不到每個人改之前是什麼，只有總數
Claude 與 Codex（審查後）都推薦 A，並吸收 C 的「逐家受影響摘要」。開期時的批量調整一次就改好幾個人，最怕誤把「覆蓋」當成「追加」；模式切換＋摘要最能防呆。

取消套用到 3 位

版面與互動 變體：原方案 B 是「可逐列編輯的表格＋統一儲存」，這裡只保留批量列＋預覽

不開彈窗：勾選後批量列直接展開兩個下拉，各有「不變更／取代為（複選）」，角色多一個「清空本期角色」。一選好，表格裡被選到的列馬上用刪除線＋橘字預覽改前改後，確認無誤再按「套用」。預覽中改變勾選，預覽跟著更新；還沒套用就離開頁面會提醒。

優點

  • 每個人改之前、改之後一目了然
  • 不用離開表格，操作最少

缺點

  • 預覽中的狀態容易和已儲存的資料混淆
  • 要處理「預覽中離開頁面」的提醒
如果組長習慣在表格上直接看結果、選了就想立刻看到差異，B 最直覺；但「未套用」的狀態要做得很明顯。

版面與互動

批量列按「批量編輯」打開右側抽屜：上半部設定共同欄位（同 A 的不變更／取代為／清空本期角色，清空可在套用前復原），下半部逐人列出「原本 → 套用後」，每個人都能單獨取消勾選排除。若選 C，S3 的單人編輯也改用同一個抽屜。

優點

  • 影響範圍最清楚，跨家成員不容易被改錯
  • 可以臨時排除某一個人

缺點

  • 步驟最多
  • 選很多人時抽屜很長
如果常有「同一人同期在兩家」的情況，C 的逐人對照最不容易出錯。
