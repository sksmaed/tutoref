S9｜上傳待驗收教案與「已歸檔教案」

對應 US-12、Workflow 4：從家內教案上傳；教案紙、投影片分兩塊選檔，按「確認上傳」才解析教案紙，再編輯教案簡介。「已上傳教案」改名「已歸檔教案」，不再出現待驗收教案。

情境

撰寫者小美在「家內教案」按「上傳教案」，選好教案紙（網路世界放大鏡!_○○○.pdf），按確認後系統解析出課程名稱、類別、年級、時長，她修正簡介後儲存，回到家內教案就看到新的一列。之後她到「已歸檔教案」只會看到以前已經歸檔的教案。

目前遇到的問題

  • C-04 家內教案沒有上傳按鈕，只能從「已上傳教案」上傳。
  • C-16 只有一個上傳區；投影片要解析完按「編輯內容」才找得到。
  • C-15 待驗收教案仍出現在「已上傳教案」，頁面也沒改名。

需要你決定

US-12 說上傳時投影片是 optional；Workflow 4 說投影片到總驗才提供上傳欄位，兩者衝突 C-17。原型採 Codex 的解讀：初驗只開放教案紙；總驗時投影片區才可以上傳，而且是選填。初驗時投影片區畫成停用的說明卡（也可以選擇直接隱藏）。如果你們希望初驗也能先附投影片，只要把投影片區改成「選填」即可。

版面與互動

家內教案的「上傳教案」帶到上傳頁，頁首固定顯示「27 冬・電光家・初驗」。第 1 步兩塊選檔區：教案紙（必填）、投影片（初驗顯示「總驗才開放」）；選檔只是暫存，按「確認上傳並解析」才開始。第 2 步編輯解析結果（解析失敗時保留附件，可重試或手動填），第 3 步儲存後回到家內教案並標出新的一列。頁面上的 500 MB 上限、「總驗通過並公告後才公開」、「歸檔過去教案」入口都是現有規則；「約 10 秒」是這次實測的解析時間。

優點

  • 「選檔 → 確認 → 解析 → 編輯 → 儲存」順序最清楚
  • 沿用現有上傳頁與教案編輯器，改動集中
  • 解析失敗時保留已選的檔案，可重試或手動填

缺點

  • 佔用整頁，步驟較多

版面與互動

不離開家內教案：按「上傳教案」開大彈窗，先在兩塊區域選檔（每個檔案都能移除或替換），按確認後彈窗切換到解析結果與簡介編輯；解析中不能關閉彈窗，失敗時保留檔案可重試；儲存後關窗，家內教案表格刷新並標出新列。下圖示範總驗時投影片區變成選填。

優點

  • 一直留在家內教案，情境不中斷
  • 上傳完立刻看到在清單中的位置

缺點

  • 解析出的簡介欄位多，彈窗會很擠
  • 解析中途關掉彈窗的行為要另外定義
如果撰寫者通常一次只傳一份、而且很少改解析結果，B 最快。

版面與互動

上傳頁分左右兩欄：左邊是兩張附件卡與教案紙預覽，右邊是解析出來的簡介草稿。解析前和 A 一樣是兩區選檔＋「確認上傳並解析」，右欄先空著；解析完成後右欄自動填入，撰寫者可以一邊看 PDF 一邊修正，最後按「儲存到家內教案」。下圖是解析完成後的樣子。

優點

  • 對照原檔修正解析錯誤最方便
  • 之後總驗替換附件也能用同一個版面

缺點

  • 版面與暫存狀態最複雜
  • 小螢幕要上下堆疊，對照效果打折
如果解析結果常常要人工修正，C 的左右對照最省時間。
