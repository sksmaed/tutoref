S10｜組長檢查各家送件與缺交

對應 US-08、Workflow 8：查看各家進度、已送出教案的附件，以及逐份的缺交名單。

情境

初驗送件截止前一天，組長要知道：哪幾家還沒送、送了哪些教案（點開教案紙確認是對的檔案）、各家缺了哪幾份、是誰的，好在群組裡追件。

目前遇到的問題

  • C-13 送件清單只有「已繳／缺少」，沒有附件連結，點教案沒反應。
  • C-12 缺交只看得到每家份數，而且放在「分配」分頁裡，不在送件清單。
  • 初驗也把「沒有投影片」算成缺檔（Codex 發現）。

三個方案共同的規則

附件連結開的是送出當下凍結的版本；「缺交教案」和「附件異常」分開計算；尚未送出的家顯示「尚未送出」，不要顯示 0 份，以免看起來像已經交齊。

版面與互動

沿用現有「本期驗收管理 → 初驗 → 教案清單」的各家進度表，加上「缺交」「附件異常」兩欄，尚未送出的家置頂。點某一家從右側打開抽屜，分成「已送出教案」（每份都有查看附件連結）與「缺交教案」（逐份名稱、姓名、缺交內容）兩個分頁。

優點

  • 從全團概況一路點到單份教案，路徑最清楚
  • 六家的規模剛好適合一張總表
  • 改動集中在現有頁面

缺點

  • 想跨家一起看所有缺交時，要一家一家點
Claude 與 Codex（審查後）都推薦 A。組長的問題通常是「某一家狀況如何」，先看總表再點進該家最符合追件習慣。

版面與互動

頁首六張小卡顯示各家狀態（送驗／缺交／附件異常），可以多選當篩選。下方用分頁切換「全團教案」與「全團缺交」：教案表每份都有附件連結、輪次與送出批次；缺交表跨家列出所有缺交教案。

優點

  • 跨家搜尋、篩選最有效率
  • 缺交名單一次看完全團，方便發公告

缺點

  • 六張卡片佔高度，手機要折疊
  • 和現有版面差異較大
如果組長習慣把全團缺交名單整理成一則公告，B 的「全團缺交」分頁最方便。

版面與互動

頁首三個可點的待追蹤數字：「尚未送出 4 家」「缺交 2 份」「附件異常 1 份」。下方依問題種類分組列出要追的事（尚未送出、逐份缺交、附件異常），每列都有對應的家別、聯絡對象與連結；完整的各家總表收在最下面。尚未送出的家只顯示「正式數量未確認」，不讀家內草稿。

優點

  • 截止前追件最有效率，先處理異常
  • 每個數字都能點進去，不會只看到總數

缺點

  • 完整進度變得不顯眼
  • 平時沒有異常時，畫面價值較低
如果組長最常在「截止前一兩天」使用這頁，C 的待辦導向最貼近當下的需求。
