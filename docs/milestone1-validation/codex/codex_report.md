## 1. 測試設定與證據規則

- 只操作 `http://localhost:3001`、`http://localhost:8001` 的隔離環境；未操作 3000／8000，未讀寫資料庫，未執行 git，未修改任何專案程式或既有規劃文件。
- 第一輪本機 Chromium 受執行環境限制；第二輪以自建 `codex-m1-ui` Docker 容器內 Playwright Chromium 實際操作 UI，連線映射仍只指向指定站。未停用或重啟原有服務。
- 一般角色透過 UI 或公開 API 登入，沒有借用真實使用者帳號、沒有改密碼。成員清單讀取與來源期成員複製包含既有資料，但沒有以真實帳號登入或個別修改其資料。
- API 日誌：[`evidence/api-log.json`](evidence/api-log.json)，以下 `API #NN` 指 `seq`。UI 操作、回應與文字：[`evidence/ui-log.json`](evidence/ui-log.json)、[`evidence/ui-supplement.json`](evidence/ui-supplement.json)。截圖：[`screenshots/`](screenshots/)。程式碼分析明確標為「程式碼」，不當成 UI 實測。
- UI 第一支腳本的瀏覽器時區預設 UTC，圖 01–10 時間需加 8 小時；後續截圖使用 Asia/Taipei。這是測試設定差異，未據此報時區缺陷。
- 第一輪只呼叫一次 `/extract`，並建立一份教案；第二輪沒有再解析。只再提交一次使用者提供的投影片，驗證送出後的權限。**Drive 授權 `invalid_grant` 是使用者提供的環境事實**，因此不能宣稱任何實體 Drive 檔案已更新或刪除；本輪可判定 API 是否接受動作、快照內容及 UI 是否正確攔截。
- 腳本：`api_harness.py`、`phase1_setup.py`、`phase2_members_schedule.py`、`phase3_upload.py`、`phase4_complete.py`、`ui_probe.cjs`、`ui_workflow.cjs`、`ui_supplement.cjs`。這些是具副作用的測試紀錄，**不要整套重跑**，尤其 phase1／phase3 會新增資料或花 LLM 費用。
